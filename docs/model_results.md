## Notes

- Leakage: features are built in dbt (`fct_features_hourly`) from data available at prediction time; `tests/assert_features_no_leakage.sql` checks every row's audit columns. Weather for the target hour is the forecast issued (h/24 + 1) days earlier.
- CAMS forecast baseline: historical CAMS forecasts don't exist; `cams_lagged` is CAMS 12h before prediction time. The true CAMS-forecast baseline is scored from live-collected forecasts (from 2026-09-28).
- One stubble/Diwali season (Oct–Nov 2025) is in the data; OpenAQ has no PM2.5 for these stations before Feb 2025.
