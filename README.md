# CheckYourAQI

Air quality forecasting and alerting for India, starting with Delhi NCR: hourly ingestion, an S3/Iceberg
lakehouse, 24/48/72h PM2.5 forecasts, a public dashboard, a text-to-SQL assistant and Telegram alerts.

Work in progress.

Data: [OpenAQ](https://openaq.org) (CPCB stations), [Open-Meteo](https://open-meteo.com), [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov).
